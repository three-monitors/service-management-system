# Система управління послугами Service Management System для Beauty Clinic.

## Опис вимог

Beauty Clinic Service Management System дозволяє клієнтам записуватися на послуги, переглядати список послуг та ціни.

**Менеджер** може додавати клієнтів, послуги та замовлення.

**Клієнт** може мати кілька замовлень, замовлення може включати кілька послуг.

**Система** зберігає інформацію про клієнтів, послуги, замовлення та продукти для інвентаризації.

## Сутності та атрибути

| Сутність    | Атрибути                      |
| ----------- | ----------------------------- |
| Клієнт      | ім'я, телефон, email          |
| Послуга     | назва, ціна, тривалість, опис |
| Замовлення  | клієнт, послуга, статус, дата |
| Призначення | клієнт, послуга, дата та час  |
| Продукт     | назва, кількість, ціна        |

## Зв'язки між сутностями

| Зв'язок               | Тип   | Як реалізуємо                             |
| --------------------- | ----- | ----------------------------------------- |
| Клієнт → замовлення   | 1 : N | `orders.client_id`                        |
| Замовлення → послуги  | 1 : N | `order_items.order_id` (проміжна таблиця) |
| Клієнт → призначення  | 1 : N | `appointments.client_id`                  |
| Послуга → призначення | 1 : N | `appointments.service_id`                 |

## Зв'язки між сутностями
 
| Зв'язок               | Тип   | Як реалізуємо                    |
| --------------------- | ----- | -------------------------------- |
| Клієнт → замовлення   | 1 : N | `orders.client_id`               |
| Замовлення → послуги  | M : N | `order_items` (проміжна таблиця) |
| Клієнт → призначення  | 1 : N | `appointments.client_id`         |
| Послуга → призначення | 1 : N | `appointments.service_id`        |
 
## Нормалізація до 3НФ
 
**1НФ (Атомарність):** Кожне поле містить одне значення.
 
**2НФ (Немає часткових залежностей):** Кожне поле залежить від усього ключа.
 
**3НФ (Немає транзитивних залежностей):** Поля залежать від ключа, а не одне від одного.
 
Таблиці вже в 3НФ:
- `clients` — незалежна таблиця
- `services` — незалежна таблиця
- `orders` — залежить від `clients`
- `order_items` — проміжна таблиця для M:N між `orders` та `services`
- `appointments` — залежить від `clients` та `services`
- `inventory` — незалежна таблиця
